Overview

Bookbinder JS is a JavaScript-based web application designed to format PDF files for bookbinding. This process, often called imposition, involves arranging pages onto larger sheets that, when printed and folded, result in a correctly ordered book or booklet. The tool aims to simplify this task for users needing to prepare documents for physical binding.

It is a rewrite of the original Bookbinder tool, now utilizing the PDF-Lib JavaScript library for its backend operations. You can find the project on GitHub.

Project Structure

The Bookbinder JS project is organized into several key folders and files:

  • src/: This directory contains the core of the application. It includes the main JavaScript source code (main.js, booklet.js, etc.), HTML partials that make up the user interface, and various utility functions.
  • public/: This folder holds static assets that are served directly. This includes images, global CSS styles (note: the wiki has its own separate CSS), and an older version of the application.
  • docs/: Here you'll find project documentation, examples of generated PDFs, and images that help illustrate the project's features and how to use them.
  • wiki/: This folder contains the project wiki, including this page, providing a more detailed guide to the project.
  • pdf-test/: This directory is dedicated to testing PDF generation. It includes various files and scripts used to ensure the PDF output is correct.

Key files in the project root include:

  • index.html: The main HTML file that serves as the entry point for the web application.
  • package.json: This file contains project metadata, such as its name, version, and dependencies (the libraries it uses). It also defines scripts for building, testing, and running the application.
  • vite.config.js: This is the configuration file for Vite, the build tool used by Bookbinder JS. It specifies how the project should be built and optimized for development and production.
